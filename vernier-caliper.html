a fixed main scale in millimetres and a sliding vernier whose N divisions span exactly N−1 main divisions — so each vernier tick falls a hair short of a main tick. open the jaws and exactly one vernier line meets a main line; which one gives the fraction. the least count — the finest you can read — is one main division divided by N.the vernier scale · Pierre Vernier 1631 · least count = 1 main division / N · the reading is the coincidence
