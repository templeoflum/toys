this looks like a single cord spiralling inward — but it is a set of separate, closed circles. each is a rope of little dark-and-light bars, and because every bar is tilted the same way against the checkered ground, the eye strings them into a spiral that isn't there. straighten the twist and the bars align with the circles, and the rings snap flat; or raise the trace to run one true circle over a ring.
