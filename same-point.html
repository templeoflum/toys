same point

 
one point on the plane, drag it. the cartesian frame names it by a horizontal step and a vertical step — (x, y). the polar frame names the same point by a distance and a turn — (r, θ). both readouts are the same point; the address is a choice of frame, not a fact about the point. move it and the numbers change together, but the point does not move because you renamed it.coordinate frames · r = √(x²+y²) · θ = atan2(y, x) · x = r·cosθ · y = r·sinθ
