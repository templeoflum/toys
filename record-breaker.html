record-breaker

 
draw values one after another from a fixed distribution; keep only the largest seen so far. every dot is a sample; the stepped line is the running maximum, and it can only ever step up — it jumps at each new record and holds flat between them. the jumps come fast early and then thin out: the n-th sample beats all n−1 before it only if it is the biggest of the n, which (all equally likely to be largest) happens with probability exactly 1/n. so the expected count of records after n draws is 1 + 1/2 + 1/3 + … + 1/n ≈ ln(n) — records get rarer and rarer, and the wait for the next one keeps growing.record values of an i.i.d. stream · P(n-th draw is a record) = 1/n · E[records after n] = H(n) ≈ ln(n) + γ · field: extreme-value theory
