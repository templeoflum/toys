each quantity is not one number but a range — a central value with an uncertainty, the interval [value − e, value + e]. carry the ranges, not the midpoints, through the arithmetic. under a sum the endpoints add: [a,b] + [c,d] = [a+c, b+d], so the half-widths add and the result range only widens — adding never sharpens a measurement. under a product it is worse: the relative errors add, so a product's fractional uncertainty grows faster than either factor's.interval arithmetic · R.E.
